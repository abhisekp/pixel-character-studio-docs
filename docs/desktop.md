# Desktop and updates

Download the Windows installer from this repository's Releases page. WebView2 and Node.js 24 must be installed; Pixelorama and Ollama are separate optional local services. Save projects through the app's Save project button before updating.

**Check for updates** checks the public release manifest. When a later version is available, the app offers Download & install, followed by an explicit restart action. Update payloads must match the public updater key embedded in the application. A missing manifest or unavailable network produces an error rather than an unsigned fallback.

Updater signing protects release authenticity. It does not provide a Windows verified publisher identity or remove SmartScreen warnings. Authenticode requires a valid code-signing certificate or a trusted signing service; no certificate was present during setup. The release workflow supports a PFX certificate stored in GitHub Actions secrets.

Reference animation: select a direction in Pixel Editor, then choose Export consistent idle animation. The eight-frame horizontal PNG preserves every source color and pixel; import it at 10 FPS using cell size original canvas plus four pixels.
