# Pixel Character Studio

A local-first desktop workspace for creating, editing and exporting consistent pixel characters for games. This is an independent studio, not an official PixelLab product.

[Game Design Document](./gdd) · [Desktop and updates](./desktop) · [Release automation](./release)

The first Windows release supports manual pixel editing, Ollama drawing, optional BYOK image providers, Pixelorama MCP, and reference-locked idle sprite-sheet export. It requires WebView2, Node.js 22.12+ (24 recommended), and running Pixelorama/Ollama services for local generation. Models and those applications are not bundled.
